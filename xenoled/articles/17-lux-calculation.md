# محاسبات روشنایی Lux — راهنمای ساده برای معماران

**لوکس (Lux)** واحد اندازه‌گیری روشنایی است: یک لومن نور در هر متر مربع. معمار و طراح داخلی بدون دانستن lux مورد نیاز هر فضا، نمی‌تواند تعداد و نوع چراغ را درست انتخاب کند. در این مقاله، فرمول‌های ساده، جداول استاندارد و مثال‌های عملی **محاسبات روشنایی lux** را برای پروژه‌های مسکونی، اداری و تجاری با رویکرد B2B ارائه می‌کنیم. تیم فنی زنولد محاسبه lux پروژه را به‌صورت رایگان انجام می‌دهد.

## Lux چیست و چرا مهم است؟

| مفهوم | واحد | معنی |
|-------|------|------|
| لومن (Lumen) | lm | کل نور تولیدی چراغ |
| لوکس (Lux) | lx = lm/m² | نور دریافتی روی سطح |
| کندلا (Candela) | cd | شدت نور در یک جهت |
| وات (Watt) | W | مصرف برق |

**مثال ساده:** چراغ ۱۰۰۰ لومن در اتاق ۱۰ متر مربع، اگر تمام نور یکنواخت پخش شود، حدود ۱۰۰ lux ایجاد می‌کند. در عمل، ضرایب اتلاف و توزیع نور این عدد را تغییر می‌دهد.

## فرمول پایه محاسبه lux

### روش ساده (تخمینی)

```
تعداد لومن مورد نیاز = مساحت (m²) × lux هدف × ضریب اتلاف
تعداد چراغ = تعداد لومن مورد نیاز ÷ لومن هر چراغ
```

**ضریب اتلاف (Maintenance Factor):** معمولاً ۱.۲ تا ۱.۵ — برای جبران کاهش نور چراغ با گذشت زمان و گرد و غبار.

### روش حرفه‌ای (Lumen Method)

```
N = (E × A) / (Φ × UF × MF)
```

- **N** = تعداد چراغ
- **E** = lux هدف (lx)
- **A** = مساحت (m²)
- **Φ** = لومن هر چراغ (lm)
- **UF** = ضریب استفاده (Utilization Factor) — ۰.۴ تا ۰.۷
- **MF** = ضریب نگهداری (Maintenance Factor) — ۰.۷ تا ۰.۹

## ضریب استفاده (UF) — چگونه تخمین بزنیم؟

UF به این بستگی دارد:
- **انعکاس سطح‌ها:** سقف روشن (۸۰٪+)، دیوار روشن، کف تیره → UF بالاتر
- **ارتفاع سقف:** سقف بلند → UF پایین‌تر
- **نوع چراغ:** پخش وسیع (wide) → UF بالاتر؛ اسپات باریک → UF پایین‌تر

| شرایط | UF تقریبی |
|-------|----------|
| سقف و دیوار روشن، downlight | ۰.۵–۰.۶ |
| سقف تیره، downlight | ۰.۳–۰.۴ |
| چراغ خطی یکنواخت | ۰.۶–۰.۷ |
| اسپات روی سطح خاص | ۰.۲–۰.۳ |

## مثال عملی ۱: اتاق اداری ۲۰ متر

**داده‌ها:**
- مساحت: ۲۰ m²
- lux هدف: ۵۰۰ (دفتر کار)
- چراغ: [Downlight](https://xenoled.lighting/product-category/down-light/) ۲۴ وات، ۲۴۰۰ لومن
- UF = ۰.۵، MF = ۰.۸

**محاسبه:**
```
لومن کل = (500 × 20) / (0.5 × 0.8) = 10000 / 0.4 = 25000 lm
تعداد چراغ = 25000 / 2400 ≈ 10.4 → 11 چراغ
```

**چیدمان:** ۱۱ downlight در سقف با فاصله تقریباً ۱.۲ متر.

## مثال عملی ۲: فروشگاه پوشاک ۸۰ متر

**داده‌ها:**
- مساحت: ۸۰ m²
- lux هدف: ۶۰۰ (ویترین و راهرو)
- ترکیب: [چراغ مگنتی](https://xenoled.lighting/product-category/magnetic-light/) اسپات ۱۵ وات، ۱۵۰۰ لومن
- UF = ۰.۴ (اسپات)، MF = ۰.۸

**محاسبه:**
```
لومن کل = (600 × 80) / (0.4 × 0.8) = 48000 / 0.32 = 150000 lm
تعداد اسپات = 150000 / 1500 = 100 اسپات
```

در عمل، زون‌بندی می‌شود: ویترین lux بالاتر، انبار lux پایین‌تر — نیازی به ۱۰۰ اسپات یکسان نیست.

## مثال عملی ۳: راهرو ۴۰ متر با چراغ خطی

**داده‌ها:**
- مساحت: ۴۰ m² (راهرو ۲×۲۰ متر)
- lux هدف: ۱۵۰
- [چراغ خطی](https://xenoled.lighting/product-category/linear-light/) ۳۶ وات، ۳۶۰۰ لومن (۱.۲ متر)
- UF = ۰.۶، MF = ۰.۸

```
لومن کل = (150 × 40) / (0.6 × 0.8) = 6000 / 0.48 = 12500 lm
تعداد خطی = 12500 / 3600 ≈ 3.5 → 4 عدد خطی 1.2 متری
```

## عوامل مؤثر بر lux واقعی

### ۱. رنگ سطح‌ها

| سطح | ضریب انعکاس |
|-----|------------|
| سقف سفید | ۷۰–۸۰٪ |
| دیوار کرم | ۵۰–۶۰٪ |
| کف موکت تیره | ۲۰–۳۰٪ |
| سنگ تیره | ۱۰–۲۰٪ |

سقف و دیوار تیره → lux واقعی کمتر → چراغ بیشتر لازم است.

### ۲. ارتفاع سقف

هر ۱ متر اضافه ارتفاع، lux روی زمین کاهش می‌یابد (قانون معکوس مجذور فاصله). سقف ۴ متری نسبت به ۲.۸ متری، تقریباً ۲ برابر چراغ بیشتر نیاز دارد.

### ۳. نوع توزیع نور

- **Wide beam (۶۰°+):** lux یکنواخت، UF بالا
- **Narrow beam (۱۵–۲۴°):** lux متمرکز، UF پایین

### ۴. UGR (خیرگی)

lux بالا با UGR بالا = فضای ناخوشایند. برای اداری، UGR زیر ۱۹ هدف است.

## ابزارهای محاسبه lux

### ۱. نرم‌افزار DIALux / Relux

استاندارد صنعت — مدل سه‌بعدی فضا، محاسبه دقیق lux، UGR، رندر.

### ۲. Excel ساده

فرمول بالا در یک شیت — برای تخمین سریع.

### ۳. تیم فنی زنولد

ارسال نقشه (PDF/DWG) + نوع فضا → دریافت BOQ و lux هر زون **رایگان**.

## lux در مقابل لومن — اشتباه رایج

مشتری می‌پرسد: «چراغ ۵۰ واتی بخرم؟» — وات به lux تبدیل نمی‌شود بدون دانستن:
- لومن چراغ (lm/W)
- UF و MF
- مساحت و lux هدف

چراغ ۳۰ واتی ۱۳۰ lm/W (۳۹۰۰ لومن) از چراغ ۵۰ واتی ۸۰ lm/W (۴۰۰۰ لومن) در بسیاری موارد بهتر است.

## lux و استاندارد ایران (ISIRI)

استانداردهای ملی روشنایی ایران (سری ISIRI) حداقل lux فضاهای مختلف را تعریف می‌کند. در پروژه‌های دولتی و بیمارستانی، رعایت ISIRI الزامی است. در پروژه‌های تجاری و مسکونی، ISIRI مرجع خوبی است اما انعطاف در طراحی وجود دارد.

## سوالات متداول

### lux و lumen چه تفاوتی دارند؟

لومن کل نور تولیدی چراغ است؛ lux نور دریافتی روی هر متر مربع سطح. lux = lumen ÷ مساحت (در شرایط ایده‌آل).

### برای اتاق ۱۵ متری چند چراغ لازم است؟

بسته به lux هدف و نوع چراغ. برای نشیمن ۱۵۰ lux با downlight ۱۸ وات (~۱۸۰۰ لومن): حدود ۳–۴ چراغ. محاسبه دقیق با فرمول بالا.

### آیا lux را می‌توان با موبایل اندازه‌گیری کرد؟

اپلیکیشن‌های lux meter تقریبی هستند. برای پروژه حرفه‌ای، لوکس‌متر کالیبره (مثلاً UNI-T) توصیه می‌شود.

### زنولد محاسبه lux رایگان انجام می‌دهد؟

بله. نقشه و مشخصات فضا را ارسال کنید؛ BOQ با lux هر زون دریافت کنید. تماس: ۰۲۱-۸۸۷۱۶۳۷۵.

### UF را از کجا بفهمم؟

در نرم‌افزار DIALux محاسبه می‌شود. برای تخمین دستی، جدول UF این مقاله یا کاتالوگ سازنده (زنولد) را ببینید.
