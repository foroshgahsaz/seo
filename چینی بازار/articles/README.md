## دسته‌بندی‌ها در سایت (slug پیشنهادی برای Laravel)

| نام در سایت | مثال مسیر |

| سرویس چینی | `https://chinibazar.ir/category/servis-chini` |
| سرویس غذاخوری | `https://chinibazar.ir/category/servis-ghaza-khori` |
| ظروف پذیرایی | `https://chinibazar.ir/category/zorf-paziraee` |
| ظروف دکوراتیو | `https://chinibazar.ir/category/zorf-dekorativ` |
| خانه و آشپزخانه | `https://chinibazar.ir/category/khane-ashpazkhane` |

اگر در فروشگاه slug دیگری دارید، یک جستجوی سراسری در `articles/*.md` برای `chinibazar.ir/category/` انجام دهید و جایگزین کنید.

## بازتولید فایل‌ها

```bash
python3 articles/_generate_articles.py
```
