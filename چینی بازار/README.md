## نحوه استفاده در Laravel

هر صفحه/مقاله در این ریپو باید این متادیتا را داشته باشد (در CMS یا Seeder):

- `title` — عنوان سئو
- `meta_description`
- `slug` — URL فارسی یا لاتین یکدست
- `h1` — یکتا در صفحه
- بلوک FAQ (در صورت امکان Schema FAQ در قالب)
- حداقل ۳ لینک داخلی (دسته، برند، محصول، اعتباری)

مسیرهای پیشنهادی در Laravel (قابل تطبیق با روت فعلی):

- `/سرویس-چینی` — دسته اصلی
- `/خرید-اعتباری` — خرید اقساطی
- `/brand/lorin` … — صفحات برند
- `/mag` یا `/راهنما` — مجله
