# استراتژی سئو و محتوا — چینی‌بازار

**دامنه:** https://chinibazar.ir  
**پلتفرم:** Laravel  
**به‌روزرسانی:** آبان ۱۴۰۵

---

## ۱. هدف کسب‌وکار (چرا سئو؟)

سئو برای چینی‌بازار یعنی **جذب خریدار آماده** از گوگل، نه فقط رتبه روی یک کلمه عمومی.

| هدف | توضیح |
|-----|--------|
| ترافیک هدفمند | کاربرانی که «خرید»، «قیمت»، «مدل» یا «برند» جستجو می‌کنند |
| فروش | تبدیل ورودی ارگانیک به سفارش (نقد + اعتباری) |
| برند | دیده شدن در جست‌وجوهای **لورین، والاس، فالکن، هرمیتاژ، پردیس** |
| تمایز | تاکید بر **خرید اعتباری/اقساطی** و راهنمای انتخاب |

---

## ۲. رقبا و موقعیت‌یابی

### ۲.۱ رقبای فروشگاهی

| رقیب | نقش در بازار | واکنش چینی‌بازار |
|------|--------------|------------------|
| نیک چینی | تخصص سرویس چینی، تنوع برند | صفحات برند غنی‌تر + مقایسه + اعتباری |
| پردیس چینی | برند و نام دامنه قوی | SEO روی «سرویس پردیس» + مدل‌ها؛ شفاف‌سازی «چینی‌بازار ≠ پردیس چینی» |
| چینی زرین | رقیب — محصول نداریم | **فقط** تحلیل کلمات و مقالات مقایسه‌ای کلی (برند ایرانی/خارجی) — **بدون** صفحه محصول زرین |

### ۲.۲ برندهای داخل فروشگاه (محور محتوا)

- لورین  
- والاس  
- فالکن  
- هرمیتاژ  
- پردیس

## ۳. معماری محتوا (Content Hub)

```
                    [صفحه اصلی chinibazar.ir]
                              |
        +---------------------+---------------------+
        |                     |                     |
  [دسته: سرویس چینی]   [خرید اعتباری]      [مجله راهنما]
        |                     |                     |
   +----+----+           (تمایز)              مقالات آموزشی
   |    |    |                                    |
 برندها  فیلترها                          مقالات مقایسه
 (۵ صفحه) (۶/۱۲ نفر، طرح)                         |
   |                                            |
 [صفحات محصول]  <-------- لینک داخلی --------+
```

**قانون طلایی:** هر مقاله → حداقل ۱ صفحه برند + ۱ دسته + ۱–۳ محصول. هر صفحه برند → جدول مدل‌های **موجود** + لینک اعتباری.

## ۴. گروه‌های کلیدواژه

### گروه ۱ — پول‌ساز (اولویت بالا)

| کلیدواژه | صفحه هدف |
|----------|-----------|
| سرویس چینی | دسته اصلی |
| خرید سرویس چینی | دسته اصلی |
| قیمت سرویس چینی | دسته + FAQ |
| خرید سرویس چینی اقساطی | صفحه اعتباری |
| قیمت سرویس غذاخوری | دسته / زیردسته |

### گروه ۲ — برند (صفحه اختصاصی هر کدام)

| کلیدواژه | مسیر پیشنهادی |
|----------|----------------|
| سرویس چینی لورین | `/brand/lorin` |
| سرویس چینی والاس | `/brand/wallas` |
| سرویس چینی فالکن | `/brand/falken` |
| سرویس چینی هرمیتاژ | `/brand/hermitage` |
| سرویس چینی پردیس | `/brand/pardis` |

### گروه ۳ — مدل و long-tail

- سرویس چینی لورین امپراطور / والاس طلایی / فالکن مارشال / هرمیتاژ نیوبن  
- سرویس چینی ۳۱ پارچه، ۱۰۸ پارچه، ۶ نفره، ۱۲ نفره  

**صفحه هدف:** محصول یا دسته فیلترشده — نه صفحه خالی.

### گروه ۴ — قیمت و مقایسه

- قیمت سرویس چینی ۶ نفره / ۱۲ نفره  
- مقایسه لورین و والاس (و سایر جفت‌های واقعی)  
- خرید سرویس چینی با اعتبار بانکی  

### گروه ۵ — آموزشی (پشتیبان فروش)

- راهنمای خرید سرویس چینی  
- سرویس ۶ نفره یا ۱۲ نفره  
- راهنمای جهیزیه  
- تفاوت چینی و آرکوپال  
- بهترین برند سرویس چینی (با CTA به برندهای خودمان)

## ۵. استاندارد کیفیت صفحه (بدون وابستگی به سئوی فنی)

هر **صفحه برند** و **محصول پرفروش** باید شامل باشد:

1. H1 شامل «خرید / سرویس چینی + نام برند»  
2. ۳۰۰–۸۰۰ کلمه متن **اختصاصی** (تکرار بین برندها ممنوع)  
3. جدول: تعداد نفر، پارچه، طرح، محدوده قیمت، موجودی  
4. بخش خرید اعتباری (روش‌های فعال)  
5. FAQ (۵–۸ سوال)  
6. گالری تصویر واقعی + توضیح طرح (طلایی/پلاتین)  
7. لینک به برندهای جایگزین و مقاله مرتبط
